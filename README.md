# ЛР №2 — вариант 2

Б24-507, N=15, Q=0, Y=26, V=2, seed=10015.

## Запуск
Python 3.13.5 (проверено), HiGHS 1.8.0 встроен в SciPy 1.17.0.

```bash
python -m pip install -r requirements.txt
python main.py > results_log.txt 2>&1
```

Запуск одной командой после установки: `python main.py`. Результаты сохраняются в `results/`. Перенаправление вывода сохраняет лог HiGHS. Для повторной генерации исходных данных: `python generate.py` (не требуется для обычного запуска).

`data.json` — входные данные; `generate.py` — генератор; `main.py` — загрузка, построение ЛП, решение, независимая проверка, жадная эвристика, сценарии и графики; `report.md` — отчёт; `results_log.txt` — фактический лог запуска. CSV имеют кодировку UTF-8 с BOM. Файлы `*_check.json` содержат проверки каждой дуги и вершины. `node_prices.csv` содержит двойственные оценки исходных правых частей, `*_flows.csv` — потоки и оценки верхних границ.

## Дополнительные задания

`bonus.py` реализует два задания: целочисленные рейсы (1 т/рейс) и сравнение узловой и путевой формулировок. Запуск только дополнительных экспериментов: `python bonus.py > bonus_log.txt 2>&1`. Для запуска всей работы одной командой: `python run_all.py > full_log.txt 2>&1`. Результаты `results/bonus_*.csv` и `results/bonus_*_check.json`, фактический лог `bonus_log.txt`. Времена в отчёте относятся к сохранённому эксперименту и при повторном запуске могут отличаться.

## Сравнение с эвристикой
`results/greedy_comparison.csv` содержит сравнение HiGHS и жадного алгоритма для всех четырёх сценариев, включая недопоставку и зазор по стоимости (только для допустимых планов). Отдельные CSV и JSON сохраняют потоки и независимые проверки каждого сценария.
